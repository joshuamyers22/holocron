# Phase 9 distribution approvals

This directory is reserved for written, candidate-specific decisions by a
qualified license/provenance reviewer. This README is procedural guidance and
is not an approval.

Each approval record must identify the pseudonymous reviewer ID used by the
beta registry, the candidate ID and exact implementation source revision, the
separately approved tag commit, decision date, approved license, provenance
process, package-name/trademark disposition, required notices, permitted beta
channel, and any conditions. The reviewer must explicitly authorize external
beta distribution.

Do not add a record on the maintainer's behalf, infer approval from silence, or
store reviewer contact details here. The matching registry entry and protected
repository variables must be updated through the reviewed release process.
